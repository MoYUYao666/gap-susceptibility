# 一次性 / 审计脚本归档（2026-10-14）

**为什么移**：按本仓库既有约定，`tools/` 根层只保留**可重跑管线**；
`_` 前缀的是为具体审计/修订**一次性**写的脚本（每篇论文修订期会产生上百个）。

**未删除** —— 它们记录了每个结论的产生过程，可原样移回 `tools/` 使用。

**命名线索**：`_pNNN_描述.py` 中的 `NNN` 是会话内的序号；
对应关系见 `HANDOFF.md` 与各脚本自身的 docstring。

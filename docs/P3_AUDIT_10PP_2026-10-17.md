## How to re-run

    cd paper3/paper_ieee
    python audit_check.py
    python audit_pdf.py

and, from the repository root:

    python tools/_p1172_verify_p3_audit.py --apply

The verifier runs both audits, checks the page counts, compares SHA-256 of the working-tree PDFs
against the corrected submission package and the upload copies, and writes
`outputs/analysis/p3_audit_refresh_2026-10-17.json`.

Current result: 0 hard failures, 0 warnings in the verifier; both audit scripts exit 0.

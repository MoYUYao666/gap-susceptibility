## 2. 结论：四条理论预言的跨域检验

**① τ/top-1 解耦 —— 海洋域成立（核心结论）**
- 海洋微调模型（oceanclip/bioclip）：λ=1 时 τ 崩塌至 ~0.46（−54%），而 top-1 保留 96.7%/83.1%——排序保持先于分类崩塌，与 A1 ImageNet 的签名一致（CLIP 保留 54% 且 τ 0.29）。
- 最强证据：oceanclip λ=0.5 时 **top-1 反而高于基线（24.44 vs 24.19）而 τ 已降 34%**——"τ 是比 top-1 更早的侵蚀信号"跨域复现。

**② CG 无信息性 —— 海洋域成立（更极端）**
- oceanclip 在 CG 低至 0.136（近零）时 top-1 仍有基线的 96.7%（ImageNet CLIP 同条件 54%）。以 CG 为健康指标的误导性在海洋域被放大：**间隙闭合≠分类健康**。

**③ 文本/图像非对称性 —— 出现边界条件（新发现）**
- BioCLIP 基座：文本侧温和（τ 0.709 vs 图像 0.463；top1 20.40 vs 18.04）✓ 与 A1 一致。
- **OceanCLIP（海洋微调后）：非对称性消失**（τ 0.461 vs 0.454；top1 23.51 vs 23.38，两侧几乎全等）。
- 解释候选（待验证）：微调使文本/图像簇结构趋于对称；或 d̂ 自估口径下文本侧相对位移增大。需与 `clip_a1_text_surgery.py` 的 Flickr 口径一致性实验复核（见 §4 下一步）。

**④ 小类目数域的"鲁棒性放大" —— 新边界条件（预告贡献点）**
- 类集 67（vs ImageNet 1000）时，海洋微调模型对 λ 手术的整体免疫力显著高于 A1 全类目（保留率 96.7% vs 54%），而通用模型（openclip/siglip）反而更脆（37–46%）。
- 与偏置场理论自洽：类数越少、类间竞争越弱，真类 margin 相对位移越不易失守（τ 类间排序 无 margin 保护 → 仍崩）。**这提示"τ 对类目数鲁棒、top-1 对类目数敏感"——可作理论扩展的定量检验（Theorem 5 的 m_c 分布随 N 缩放的预测）。**

**⑤ 域特化增益确认**：海洋微调 +2.5pp 于基座（24.19 vs 21.70），且把模型从"λ 敏感型"变为"λ 鲁棒型"——域特化与手术鲁棒性挂钩，值得写进综述"挑战：跨船泛化"的呼应点。

### ③ 类目数扫描：top-1 保留率随 N 的依赖（发现④的细化）

## 结论

1. **τ 在 epoch 1–3 单调侵蚀（0.833→0.823）后平台化**——侵蚀先于任何其他信号出现；
2. **top1 全程平坦**（58.45–58.63，波动 <0.2pp）——top1 完全看不见这个侵蚀；
3. **val loss 平坦略升**（2.464→2.472）——比 τ 更晚、更弱地反映同一趋势；
4. 与 A1 §5.5 重训轨迹一致（那里 τ 从 1.0 早降至 0.75）；本配置（r8 both）侵蚀幅度
   较小（Δτ≈0.01），诚实表述：**τ 是三者中最早、最敏感的信号，方向与 A1 一致，
   幅度因配置而异**。

# 一阶残差与有效域（A2 · #3，草稿 v2，2026-08-16）

> 目标：精确计算 A1 偏置场近似中被丢掉的项，分清"排序层面"与"数值层面"两种有效域，
> 并把 Paper A 的 β 理论"40× 失效"统一到同一判据。
> 常数：‖g‖=0.815、σ_m=0.067、mean(x·d̂)≈0.05、top-5 典型 margin d_typ≈0.02–0.03
> （d_typ 待 `tools/clip_a1_margins.py` 精确化）。

## 1. 精确表达式

$$ x' = \frac{x+\delta}{\sqrt{1+2x\cdot\delta+\|\delta\|^2}}, \qquad
   s'_c = \frac{s_c + \delta\cdot t_c}{\sqrt{1+2\delta\cdot t_c+\|\delta\|^2}} . $$

图像侧（δ = λ‖g‖d̂）：分子 = s_c + λ‖g‖m_c，分母与 c 无关；
文本侧（t_c 平移）：分子 = s_c + δ·x（与 c 无关），**分母 = √(1+2λ‖g‖m_c+λ²‖g‖²) 与 c 有关**。

## 2. Lemma 0（图像侧排序对任意 λ 精确成立）

图像侧 $s'_c$ 的排序 = $(s_c + \lambda\|g\|m_c)$ 的排序（正公共分母不改变序）。
因此成对反转条件 $\lambda\|g\|(m_j-m_i) > s_i - s_j$（`theory_tau_bound.md` Lemma 1）
**不是一阶近似，而是对所有 λ 精确成立**。τ(λ) 曲线的全部形状来自
"margin 分布 × m 差分分布"，与归一化非线性无关。

## 3. 文本侧：一阶精确零反转，重排是纯二阶效应

文本侧分母逐类变化，展开 $(1+u)^{-1/2}=1-\tfrac12 u+\tfrac38u^2+\dots$：

$$ \Delta s_c = \delta\cdot x \;-\; \lambda\|g\|\,m_c\,s_c
   \;+\; \big(\tfrac32(\lambda\|g\|m_c)^2 - \tfrac12\lambda^2\|g\|^2\big)s_c \;+\; O(\lambda^3). $$

- **一阶**：只有 δ·x（逐图像常数）→ 排序零改变——这就是 A1 Prop 4 的精确版；
- **二阶**：出现逐类项 $\propto m_c s_c$ → 重排从 O(λ²) 才开始；
- 量级：二阶排序差分 ≈ λ²‖g‖²·σ_m·s_c ≈ 0.01·λ²，对比图像侧一阶差分 λ‖g‖σ_b ≈ 0.077λ。
  **比值 ≈ 0.13λ**：λ=1 时文本侧重排强度只有图像侧的 ~13%，λ=2 时 ~26%——
  与实测吻合（λ=1：文本侧 τ 0.43 基本无损；λ=2：降到 0.36 开始可见侵蚀）。

**这解释了"为什么文本侧破坏小"的全部定量来源**：不是小常数，而是"一阶项恰好是逐图像常数"这一结构性事实。

## 4. 数值层面（位移大小）的展开与有效域

对图像侧位移做三阶展开（u = 2λ‖g‖(x·d̂)+λ²‖g‖²）：

$$ \Delta s_c = \underbrace{\lambda\|g\|m_c}_{\textcircled{1}}
 - \underbrace{\lambda\|g\|(x\cdot\hat d)\,s_c}_{\textcircled{2}}
 - \underbrace{\lambda^2\|g\|^2(x\cdot\hat d)\,m_c}_{\textcircled{3}}
 - \underbrace{\tfrac12\lambda^2\|g\|^2\,s_c}_{\textcircled{4}}
 + \underbrace{\tfrac32\lambda^2\|g\|^2(x\cdot\hat d)^2 s_c}_{\textcircled{5}} + O(\lambda^3). $$

量级（λ=1，s_c≈0.3，x·d̂≈0.05）：①≈0.055，②≈0.012，③≈0.002，④≈0.10，⑤≈0.002。
②④⑤ 是"逐图像×分数"项：对**排序**零作用（被 Lemma 0 的公共分母吸收），
只影响位移数值。Pearson r=1.000（λ=1）正是"位移≈λ‖g‖m_c 的类间结构未被动摇"的体现。

**数值有效域**（位移近似好坏的判据）：②④ 相对① 不可忽略的条件
λ‖g‖(x·d̂) ≳ 1 ⟹ **λ ≳ 1.2**（②）；½λ²‖g‖²s_c ≳ λ‖g‖σ_m ⟹ **λ ≳ 2σ_m/(‖g‖s_c) ≈ 0.55**（④，对位移）。
结论：位移数值的一阶近似在 λ<0.5 优秀、λ∈[0.5,2] 过渡、λ≥2 需二阶修正；
**但排序理论在图像侧全 λ 精确**——两者有效域完全不同，必须分开陈述。

## 5. 与 Paper A β 理论的统一判据

Paper A 的 ODE/β 模型刻画的是**鸿沟数值（CG）**的动态——属"数值层面"，适用 §4 的
判据（λ‖g‖ ≪ 1，即 λ ≲ 0.5–1）。其"40× 失效"= 远超数值有效域（40×‖g‖≈33 ≫ 1），
与 A1 的"λ=1 位移仍可用但 λ=2 已过渡"是同一物理。统一陈述：

> **一阶模型的有效域按对象分两类**：排序量（τ、top-1、反转条件）在图像侧平移下
> 对任意 λ 精确；数值量（CG、位移大小）仅在 λ‖g‖ ≲ 1 内可信。

## 7. 遗留问题

- s_c 与 margin、m 与 margin 的相关性（margins 数据到手后复核 Φ̄ 模型的独立性前提）；
- 正交平移 r⊥d̂ 的对应推导（b 换成 r·t_c，σ_b 更小 → O 家族更温和的定量化）；
- 负 λ：图像侧 Lemma 0 与反转条件自动涵盖（λ 变号），文本侧二阶项符号不对称
  （λ³ 项出现）——如需负向文本平移再补。

## 结论：训练期类别对齐单调**有害**于零样本（完整的剂量-响应）

1. **三个指标全部单调**：τ 0.711→0.611 ↓、top1 58.05→54.36 ↓、val loss 2.364→2.103 ↑
   （val 越好、零样本越差）——正则项真实起效且方向明确；
2. **与事后正对照（78.6%）形成对照**：正对照=真标签+事后+冻结模型 → 提升；
   训练正则=伪标签+优化中 → 损害。差异来源：(a) 伪标签 ~41% 错误，把图像拉向
   错误质心；(b) 训练期对齐破坏对比排序（τ↓），与 A1 偏置场叙事一致；
3. **对 A1 的贡献**：更完整的消融——"post-hoc class alignment helps; training-time
   class alignment hurts"——把 A1 的"扰动空间≠训练目标空间"从"无效果"升级为
   "方向相反"，消融更有信息量。

## D — WaterBench 海洋检索基准实测（投向 A2 内部）

**目标**：解决 §4.2.2 的开放问题——"检索是否跟踪 CG"（A1 通用域定律 vs 我们海洋域反例，后者被归因于类条件伪对）。用**自然图文对**做一个规范的 caption 检索检验。

**数据来源（按优先级，均需先核验规模/格式）**：
1. `ayushprd/WaterBench`（HF 数据集，链接 https://huggingface.co/datasets/ayushprd/WaterBench ，无论文 → 按数据集引用）——核对：图像数、是否含 caption/QA 文本、许可；
2. 回退：iNaturalist API 观察记录的 **description 字段**（research-grade + CC，取"图像+描述文本"自然对）；
3. 再回退：从 rare-species 子集派生（类名模板不满足"自然图文"，仅作对照组）。

**协议**（与 A2 完全同口径）：
- 枚举图文对 → 编码（oceanclip / bioclip / openclip / siglip）→ 图像侧 λ ∈ {0, 0.5, 1, 2}（+ 文本侧 λ=1 可选）；
- 指标：i2t/t2i R@1（**caption 级检索**）、τ、CG；
- **判据**：R@1(λ) 是否与 CG 同步（CG 在 λ=1 近零、λ=2 回弹）——若 R@1 跟随 CG 回弹形态 → "检索跟踪 CG"跨域成立（§4.2.2 改为复现）；若仍单调随 τ → 边界条件（如实报告 + 解释）。

**产出**：`tools/clip_ocean_waterbench.py`、`outputs/ocean_waterbench.json`、论文 §4.2.2 升级段（+表或并入现有谱系表）。
**成本**：下载+编码 ≈ 1–2h 本地（4060）。
**成功率评估**：高（若 WaterBench 可用）；主要风险 = 数据格式不可用 → 走回退链。

## E — 声呐/声学域 λ 手术（独立成文 A3）

**目标**：验证理论是否**模态无关**——在声学感知（侧扫声呐成像）上重放全部协议，检验：① τ 精确预测器是否逐值命中；② 域微调是否同样压平 σ_m（"域亲和"故事在第二个物理模态是否成立）；③ 非对称性/退化表现。

**数据（核验后选用 1 个）**：真实声呐 ATR 数据集候选——SonarMNIST、MARble、side-scan 公开集（**第一步：OpenAlex/web 核验名称/作者/DOI/类目数**；要求 ≥8 类、每类 ≥8 图，与 A2 协议兼容；不可用则换候选）。

**模型**：无公开"声呐 CLIP"→ 自建 **SonarCLIP 原型**：CLIP ViT-B/32 基座 + 声呐图+类名文本对 LoRA 微调（10ep，同 A2 判别实验调度）→ 得到 (基座, 声呐适配) 对，复现"域微调压平 σ_m"的实验结构。

**协议**：与 A2 逐字对齐（d̂ 估计、λ 网格、margins 精确预测、2×2 判别、PEFT 保护；退化压力测试可加：声呐噪声/阴影条带退化）。
**判据**：τ 预测 diff ≤ 0.05 = 算子模态无关 ✓；σ_m(声呐FT) ≪ σ_m(基座) = 域亲和故事跨模态 ✓；否则 = 模态边界（也是好结果）。

**产出**：`paper_a3/`（A3：*Alignment health across modalities* 英文稿 + 中文译本模式照旧）、`tools/clip_sonar_*.py`、`outputs/sonar_*.json`、GitHub 归档（main 线）。
**成本**：数据集下载 + 微调 + 全协议 ≈ 1–2 天本地（4060）。
**成功率评估**：中高；主要风险 = 数据集类目/质量（回退：换候选集或降级为"单模态内部检验"）。

## 3. 结论（可写入扩展版/回应审稿人）

1. **排序保持签名跨架构复现**：解码器式 VLM 上，τ 剂量-响应、图像侧崩塌、
   CG 非单调（λ=1 时 0.867→0.155 而分类仍远未崩塌到零）全部成立。
2. **非对称的架构差异被理论预言并证实**：CLIP 文本侧因嵌入归一化引入
   O(δ) 逐类项 → 轻微退化（τ 0.43）；解码器 VLM 的 unembedding 行无归一化约束 →
   平移是一阶精确零重排（τ=1.000 全 λ、top1 完全不动）。见
   `docs/theory_first_order_residual.md` §3 的同一公式两侧应用。
3. **反例同样成立**：Qwen 上 λ=1 时图像侧 CG 缩到 0.155（<冻结 0.867 的 1/5），
   top1 仅从 17.06 降到 15.34——"缩小鸿沟"依然没有带来分类收益，τ 才是操作变量
   （τ 0.482 < 冻结 1.0）。

## 4. 已知限制（诚实披露）

- 首 token 协议低估绝对 top1（多 token 类名并列）；若需要接近 CLIP 量级的 top1，
  需升级到完整 logprob（KV-cache 续写）——留作扩展版的可选加固项。
- 只测了 2B 一个解码器模型；7B 与更多架构（LLaVA）可后续补。
- 负 λ 图像侧同样单调退化（τ 0.434@−2），与 A1 的负向崩坏一致。

**三项结论**：
1. **P1 成立**：top-1 与 τ 在所有家族中同步移动；CG 与之解耦——最强反例：T λ∈{0.5,1} 时 **gap 缩小但分类崩塌**（"缩小 gap = 更好"的朴素主张被证伪）
2. **P2 需修正**：全局低秩扰动（k=1–64）与高斯同破坏力——**保序性不来自扰动的全局子空间性质**，而来自**输入依赖的场结构**（P 类收缩是输入依赖的构造性场：top-1 反超 frozen 至 78.6%）。真实 LoRA 扰动正是输入依赖场 → 与观测一致
3. **任务敏感度谱系确认**：NCC（质心分类，完全平坦）< zero-shot（对 τ 敏感）< retrieval（对 CG 敏感）——三档分层清晰

**跨模型复现 ⏸**：OpenCLIP（HF 快照缺 config.json、open_clip 缓存空）与 SigLIP（无权重）均推迟——需取权重后补跑，模型规则不变（服务器/迅雷）。

## 二、核心假设（v4 终版，夜跑全部完成）

**P1（强成立，含真实域剂量-响应）**：top-1 与 τ 强耦合、与 CG 解耦。真实 checkpoint 的剂量-响应（`outputs/a1_e2b_e3b.json`）：τ = 1.000 / 0.795 / 0.122 / −0.083 对应 top-1 = 59.26 / 59.82 / 7.42–7.02 / 0.14 —— **τ 完美单调预测零样本崩塌**。

**P2（v4，E2b 修正后终版）**：保序性 ≠ 低秩性（全局低秩 k=1–64 与高斯同破坏）、≠ 输入依赖性（E2b 每图独立低秩场 k=1/16/64 → τ 0.44/0.44/0.44，与全局低秩无差别）——**保序性的来源是扰动场与类结构的对齐**（P 类收缩正对照 top-1 反超 frozen 至 78.6%）。随机场（无论全局/逐图 × 各向同性/低秩）都按幅度成比例破坏分类。

**P3（成立）**：任务敏感度三档谱系——NCC 质心分类（全干预平坦 ≈69%）< zero-shot 分类（τ 敏感）< 检索 R@1（CG 敏感）。

**完整叙事（可写论文）**：gap 与排序破坏是嵌入扰动的两个正交轴；零样本健康的正确监控量是 τ（排序保持），不是 CG/gap；"缩小 gap 即更好"在全局干预下被反例证伪（T λ=0.5/1：CG 0.41/0.01 但 top-1 47.6/32.0）；LoRA 保序的原因是其扰动场与任务几何对齐（梯度驱动），而非低秩或输入依赖。

**剩余待补（不阻塞论文初稿）**：跨模型复现（OpenCLIP 快照缺 config.json、SigLIP 无权重——需取权重后补跑）；可选 Qwen 云端推广。

### 实验 2（新核心）：扰动子空间谱系
合成四类嵌入扰动，测 τ 与 top-1 的谱系排序：
1. 全局平移（已有数据）
2. 各向同性高斯噪声（不同 σ）
3. **低秩结构化扰动**：img' = normalize(img + P_k·ε)，P_k 为 rank-k 投影（模拟 LoRA 子空间，k ∈ {1,4,16,64}）
4. **输入相关保序场**（正对照）：沿"类内方向"的轻微拉伸（保持类间次序的构造性扰动）
- 预测：τ 排序 = 保序场 > 低秩(小k) > 高斯(小σ) > 全局平移；top-1 与 τ 强相关
- 产出：扰动类型 × 幅度 × (τ, top-1) 相位图（论文主图 2 + 理论小节的实证锚点）

## 四、论文大纲（v2，6–8 页）

1. **Intro**：gap 被当作通用 alignment 健康指标；真实微调反例（gap↑、零样本不掉）→ 提问：gap 什么时候是健康指标？

3. **Analysis**：gap 分量与排序破坏分量的正交分解（把扰动场分解为全局平移分量 + 剩余场）；保序条件的形式化（扰动剩余场需近似等距于类间方向）
4. **Gap Surgery 相位图**（实验 1）
5. **扰动子空间谱系**（实验 2）→ 支持保序条件
6. **真实微调验证**（实验 3：116 实验 + SigLIP + DTD/Food101）
7. **Discussion**：gap-aware 监控的适用边界（gap 只对检索族任务是健康指标；分类族应监控 τ/排序结构）；与 visual fragility 的兼容性；局限

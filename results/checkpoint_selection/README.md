# Checkpoint selection

Run `python -B replay.py` with NumPy installed. This replays all canonical numeric trajectories, calibration-only orientation, selection losses, clustered intervals and utility sensitivities. No model or dataset download is required.

The bundle contains 504 contrastive trajectories (1,512 checkpoints), 48 small VQA trajectories (144 checkpoints), and four separate six-epoch schedule reruns. A trajectory is the statistical unit; shared tasks, data and seeds are not independent datasets. The classification and image-to-text fields are exact aliases here, so the four-field utility is not four independent outcomes. The empirical residual fallback is not a certified coverage guarantee. VQA checks are historical small same-shard checks, not independent field validation. Schedule comparisons are descriptive, with only two evaluation seeds, not causal duration evidence.

`producer/` retains historical training computations with configurable `GS_WORKSPACE` and `GS_VQA_DATA` paths. `commands.json` gives isolated-output commands; the schedule trainer is bound to its frozen hash, while other commands are reconstructions from metadata rather than a fully archived launch history. Matrix training requires `--apply` and refuses pre-existing output files; use a fresh output folder for every retry or epoch schedule. These scripts require separately obtained licensed datasets, cached models and the corresponding GPU training stack (PyTorch, Transformers, PEFT, Pillow, pandas, scikit-learn and optional bitsandbytes). They are not run by the offline replay. Match the per-record metadata rather than assuming their defaults describe every archived block. No fresh GPU reproducibility claim is made by this maintenance release.

`provenance.json` pins exact source versions and transformations. The registry deliberately excludes duplicate primary/VQA pilots and partial fill runs. The canonical archived version is used rather than conflicting later copies.
